# Tool Default Values

- `js-reverse_list_network_requests`: First look at the default results on the first page, if not enough then turn the page
- `js-reverse_search_in_sources`: Default `excludeMinified=true`
- `js-reverse_get_script_source`: Read-only small snippet, the full source code is best used with `js-reverse_save_script_source`
- `js-reverse_break_on_xhr`: Only fill in URL fragments that can reliably hit
- `js-reverse_get_paused_info`: By default, first look at `frameIndex=0`
